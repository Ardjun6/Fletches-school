Week 1

SQL: Selecteren

Introductie tot databases en SQL. Je leert wat een Relational Database Management System (RDBMS) is, hoe je data selecteert met SELECT en FROM, en hoe je basisbewerkingen uitvoert zoals COUNT, SUM en AVG.

Lesdoelen

A

Les A: Databases & SQL Introductie

  • De student kan uitleggen wat een RDBMS is en hoe tabellen zich tot elkaar verhouden.
  • De student kent het verschil tussen de rol van een ICT Beheerder en een Data Scientist bij databases.
  • De student kan uitleggen wat SQL is en waarvoor het gebruikt wordt.
B

Les B: SELECT, COUNT & Bewerkingen

  • De student kan data selecteren met SELECT en FROM.
  • De student kan SELECT DISTINCT en COUNT toepassen.
  • De student kan basisbewerkingen (SUM, AVG, MIN, MAX) uitvoeren in SQL.

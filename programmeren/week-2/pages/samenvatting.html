Key Points

  • OOP biedt herbruikbaarheid, structuur en representatie van real-world entiteiten
  • Een class bundelt data (attributen) en gedrag (methoden) samen
  • De constructor (__init__) geeft objecten hun beginstatus
  • Data preprocessing stappen kunnen gebundeld worden in een OOP class (DataCleaner)
  • OOP maakt code herbruikbaar: schrijf een class eenmaal, gebruik in meerdere projecten
  • Missende waarden analyseren, visualiseren, verwijderen en invullen zijn de vier preprocessing stappen
